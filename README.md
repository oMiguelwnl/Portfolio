# Portfólio - Miguel Rafael

## 📜 Descrição

Portfólio Pessoal, desenvolvido com o objetivo de apresentar meus principais projetos, habilidades técnicas e trajetória na área de desenvolvimento. O site é **totalmente responsivo**, garantindo uma navegação fluida em dispositivos móveis, tablets e desktops.

## 📸 Demonstração

Acesse a versão ao vivo aqui: [miguelrafael.dev](https://portfolio-miguel-rafael.vercel.app/)

![Demonstração do Portfólio](https://github.com/user-attachments/assets/d5e1af37-5261-48f2-95d2-3da08cd1c6a1)

## 🔨 Funcionalidades

- Apresentação profissional com biografia e foto.
- Lista de projetos com descrição, tecnologias usadas e links.
- Links diretos para GitHub, LinkedIn e e-mail.
- Alternância de tema via Theme Context.
- Design limpo, moderno e adaptado para qualquer tela.
- SEO otimizado para melhor desempenho nos motores de busca.

## 🚀 Tecnologias e Bibliotecas

- [Next.js](https://nextjs.org/) – Framework React com suporte a SSR e SSG.
- [TypeScript](https://www.typescriptlang.org/) – Tipagem estática para JavaScript.
- [Tailwind CSS](https://tailwindcss.com/) – Framework de estilização utilitária.
- [Framer Motion](https://www.framer.com/motion/) – Animações suaves e interativas.
- [Formik](https://formik.org/) – Manipulação de formulários em React.
- [Yup](https://github.com/jquense/yup) – Validação de schemas de formulário.
- [React Hot Toast](https://react-hot-toast.com/) – Notificações rápidas e elegantes.
